Manual do Cliente

Como editar o seu site

Um guia simples, passo a passo, para você mudar textos, botões, cores e imagens direto na hospedagem — sem medo.

FABI FELINTRO TRAINER
!

Leia antes de começar (3 regras de ouro)

1. Sempre faça uma cópia de segurança Antes de editar qualquer arquivo, baixe ele para o seu computador (botão direito → Baixar). Se algo der errado, é só subir a cópia de volta.
2. Mexa só no texto, nunca nos sinais Você vai trocar apenas o que está escrito. Nunca apague os sinais < > " / — eles são a "estrutura" da página.
3. Mudou? Atualize forçando o site Depois de salvar, abra a página e aperte Ctrl + Shift + R para o navegador mostrar a versão nova (e não a antiga guardada na memória).
1

Onde os arquivos ficam (Hostinger)

  1. Acesse hpanel.hostinger.com e faça login.
  2. No menu, clique em Sites → escolha o seu site → Gerenciador de Arquivos.
  3. Entre na pasta public_html. É aqui que o seu site mora.
  4. Para editar um arquivo: clique com o botão direito nele → Editar.

Os arquivos principais do seu site:

ArquivoÉ a página…
index.htmlPrincipal (a home, primeira que abre)
planos.htmlDos planos / preços
lombar.htmlDo Protocolo da Lombar
css/style.cssAs cores e o visual do site
img/ (pasta)Onde ficam todas as imagens
Dica de ouro para achar o que quer editar Dentro do editor, aperte Ctrl + F e digite um trecho do texto que aparece no site (ex: "Comprar Agora"). Ele leva você direto ao lugar certo.
2

Trocar um texto (título, frase…)

  1. Abra o arquivo da página onde está o texto (ex: index.html).
  2. Aperte Ctrl + F e digite o texto atual para encontrá-lo.
  3. Troque somente as palavras, deixando os sinais ao redor intactos.
  4. Clique em Salvar (ícone do disquete ou Ctrl + S).

Exemplo — trocar o título. Você só mexe no que está marcado:

<h1>Transforme seu corpo</h1> ↑ troque só o texto. Não apague <h1> nem </h1>
3

Trocar o texto de um botão

Um botão é um link com visual de botão. O texto fica entre > e <:

<a href="planos.html" class="btn btn-primary">Comprar Agora</a> ↑ troque só "Comprar Agora" pelo texto que quiser
Resumo O que estiver entre > e </a> é o que aparece escrito no botão.
4

Trocar o link de um botão

O endereço para onde o botão leva fica dentro de href="...". Troque só o que está entre as aspas:

<a href="https://wa.me/5511953532718" class="btn">Falar no WhatsApp</a> ↑ troque só o endereço entre as aspas " "
Cuidado Mantenha as aspas " no começo e no fim do endereço. Sem elas, o link para de funcionar.
5

Trocar uma cor do site

As cores ficam no arquivo css/style.css. A cor dourada da marca está guardada em um único lugar — mudou ali, mudou no site inteiro.

  1. Abra css/style.css para editar.
  2. Aperte Ctrl + F e procure por --accent-gold:
  3. Logo depois dos dois-pontos vem o código da cor: #D4AF37. Troque esse código pelo da cor nova.
  4. Salve e atualize o site com Ctrl + Shift + R.
--accent-gold:#D4AF37; ↑ troque só o código #D4AF37 pela nova cor

Cores principais do site (o código sempre começa com #):

CorOnde apareceCódigo
DouradoBotões, destaques, detalhes#D4AF37
PretoFundo principal#000000
BrancoTextos sobre o preto#FFFFFF
Verde WhatsAppBotão flutuante do WhatsApp#25D366
Onde pegar o código de uma cor nova? Pesquise no Google por "seletor de cores" (color picker). Escolha a cor e copie o código que começa com #.
A página do Protocolo da Lombar é à parte As cores da lombar.html ficam dentro do próprio arquivo (no começo, na parte <style>), e não no style.css.
6

Trocar uma imagem

O jeito mais fácil e seguro: dê à imagem nova o mesmo nome da antiga. Assim você nem precisa mexer no código.

  1. Descubra o nome da imagem atual. No editor da página, procure por <img e veja o trecho src="img/nome.webp".
  2. No seu computador, renomeie a imagem nova com exatamente esse mesmo nome (inclusive maiúsculas/minúsculas).
  3. Na Hostinger, entre na pasta img/ e clique em Upload (enviar). Confirme substituir a antiga.
  4. Atualize o site com Ctrl + Shift + R.
<img src="img/Lombar.webp" alt="..."> ↑ este é o nome do arquivo de imagem que a página usa
O nome precisa bater certinho O servidor diferencia maiúsculas de minúsculas. Lombar.webp e lombar.webp são considerados arquivos diferentes. Se a imagem não aparecer, quase sempre é o nome escrito diferente.
7

Se algo der errado

  1. Não entre em pânico — nada quebra de verdade. 🙂
  2. Suba de volta a cópia de segurança que você baixou antes de editar (lembra da regra de ouro nº 1?).
  3. Se não tiver a cópia, me chame que eu resolvo rapidinho.
Mudança não apareceu? Quase sempre é a memória do navegador (cache). Aperte Ctrl + Shift + R na página. Se ainda assim não aparecer, confira se você clicou em Salvar.
